WebGL Studio is a full-featured browser-based 3D graphics IDE. Write and preview WebGL2 shaders live, build Three.js scenes interactively, generate 3D models with AI (Stable Diffusion), and manage projects — all without leaving the browser.

## ✨ Features

- **Live WebGL2 code editor** — CodeMirror 6, real-time rendering preview, FPS counter
- **Full renderer API access** — `renderer.getGL()`, `renderer.clear()`, and more
- **Three.js World Editor** — interactive 3D viewport with orbit controls, grid, gizmos, and transform controls
- **Primitive library** — add cubes, spheres, and cones to the scene
- **Per-object shader editor** — custom GLSL vertex + fragment shaders per object
- **Material types** — Basic, Phong, and Custom (GLSL)
- **AI model generation** — Stable Diffusion integration for 3D asset creation
- **Project management** — persistent project storage and management
- **Keyboard shortcuts** — ⌘1–⌘6 to switch tabs instantly

## 🚀 Quick Start

```bash
git clone https://github.com/RhythrosaLabs/webgl-studio.git
cd webgl-studio
npm install
npm run dev
```

## 🛠️ Tech Stack

- **React 18 + TypeScript 5** — UI framework
- **Three.js r162** — 3D scene engine
- **WebGL2** — graphics API
- **CodeMirror 6** — in-browser GLSL/JS editor
- **Stable Diffusion** — AI model generation
- **Vite 5** — build tool
